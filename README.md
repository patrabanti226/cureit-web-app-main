# 🏥 CureIt – Medicine Information Web Application

CureIt is a web-based application designed to provide detailed information about medicines, including dosage instructions, recommended timing, and pricing.  
The goal of this project is to help users understand how to properly take prescribed medicines in a simple and accessible way.

---

## 📌 Project Overview

This application allows users to:

- View detailed medicine information
- Understand dosage instructions
- Check when to take medicines
- View medicine cost details
- Navigate through a clean and user-friendly interface

This project demonstrates full-stack development fundamentals using Node.js and Express with server-side rendering.

## ⚙️ Installation & Local Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/cureit-web-app-main.git
```

### 2️⃣ Navigate to the project directory

```bash
cd cureit-web-app-main
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the application

```bash
node index.js
```

If nodemon is installed:

```bash
npx nodemon index.js
```
